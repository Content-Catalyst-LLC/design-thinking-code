# Validation Protocol

Use this checklist before interpreting model outputs.

## Data validation

- [ ] Every candidate experiment has a clear name.
- [ ] No duplicate experiments exist.
- [ ] All required criteria are present.
- [ ] All required scores are numeric.
- [ ] Scores are in the expected range.
- [ ] Scenario weights sum to 1.0.
- [ ] Risk components are documented.
- [ ] Evidence quality is documented.
- [ ] Team confidence is documented.
- [ ] Ethics-review diagnostics are documented.

## Research validation

- [ ] Each experiment has a clear learning question.
- [ ] Each experiment has an explicit hypothesis.
- [ ] Evidence standards are documented before testing.
- [ ] Affected stakeholders are identified.
- [ ] Less visible or high-burden stakeholders are included where relevant.
- [ ] Ethical risks are reviewed.
- [ ] Operational risks are reviewed.
- [ ] Interpretive risks are reviewed.
- [ ] Scaling risks are reviewed.
- [ ] The revision pathway is defined.

## Interpretation validation

- [ ] Rankings are compared across scenarios.
- [ ] Monte Carlo stability is reviewed.
- [ ] Weight sensitivity is reviewed.
- [ ] High-uncertainty experiments are not overinterpreted.
- [ ] High-risk experiments are not selected solely because they are actionable.
- [ ] Ethics-review priorities are reviewed before implementation.
- [ ] The next research or prototype step is clearly defined.
