# Model Card: Co-Design and Participatory Design Process Model

## Model name

Co-Design and Participatory Design Process Model

## Intended use

The model supports transparent evaluation of participatory design activities across representation, accessibility, participant influence, trust, evidence quality, implementation accountability, decision impact, affectedness weighting, compensation, feedback-loop quality, tokenism risk, and ethical risk.

## Not intended for

- Certifying a process as legitimate without participant review.
- Replacing community judgment.
- Replacing ethical, legal, accessibility, privacy, or governance review.
- Automating public, community, or institutional decisions.
- Treating participation scores as objective proof of justice.
- Using participation analytics to manage or surveil participants.

## Inputs

- Activity name.
- Activity type.
- Design stage.
- Representation.
- Accessibility.
- Participant influence.
- Trust quality.
- Evidence quality.
- Implementation accountability.
- Decision impact.
- Ethical risk.
- Affectedness weight.
- Compensation quality.
- Feedback-loop quality.
- Tokenism risk.
- Optional participant-group coverage data.
- Optional participatory prototype-learning data.
- Optional participation risk-register data.

## Outputs

- Participation quality.
- Affectedness-adjusted quality.
- Equity participation index.
- Implementation legitimacy index.
- Participatory evidence index.
- Learning priority.
- Process resilience.
- Scenario rankings.
- Monte Carlo rank stability.
- Bootstrap stability.
- Random-weight sensitivity.
- Participant-group attention priorities.
- Participation process summary.
- Risk-register priority.

## Responsible use

Use the model to support deliberation, not replace it. Treat weak representation, low influence, missing access supports, high tokenism risk, high ethical risk, and unstable rankings as reasons for process redesign.
