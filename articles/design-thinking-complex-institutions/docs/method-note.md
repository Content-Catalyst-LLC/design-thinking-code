# Method Note: Institutional Design Readiness

This folder provides a transparent decision-support framework for evaluating institutional design options. It treats institutional design as a relationship among public value, authority, capability, governance, burden, equity, data readiness, frontline fit, trust, maintenance, coordination complexity, and implementation risk.

## Core models

Institutional change readiness:

\[
R_i = w_dD_i + w_aA_i + w_cC_i + w_fF_i + w_pP_i + w_gG_i + w_tT_i - w_bB_i - w_kK_i
\]

Institutional absorption capacity:

\[
A_i = \alpha O_i + \beta S_i + \gamma M_i + \delta L_i + \theta Q_i
\]

Stakeholder burden:

\[
B_g = \lambda T_g + \mu C_g + \nu E_g + \rho D_g + \sigma U_g
\]

## Recommended use

Use this model to support:

- institutional design portfolio review;
- service-system redesign;
- public-sector design research;
- implementation planning;
- governance review;
- organizational change sequencing;
- burden-reduction and public-value analysis;
- data-system readiness review;
- complex-institution learning systems.

## Interpretation

Scores support deliberation. They do not replace legal review, budget authority, public accountability, staff participation, community leadership, accessibility review, or executive judgment.
