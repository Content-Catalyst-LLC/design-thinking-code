# Implementation and Absorption Protocol

## Purpose

Institutional designs fail when they cannot be absorbed into real operations. Absorption depends on ownership, staffing, funding, policy fit, governance, data readiness, frontline fit, and maintenance.

## Implementation checks

- [ ] Operational owner assigned.
- [ ] Governance owner assigned.
- [ ] Budget source identified.
- [ ] Frontline workflow tested.
- [ ] Policy/legal constraints reviewed.
- [ ] Data-system dependencies mapped.
- [ ] Training and support plan defined.
- [ ] Maintenance owner assigned.
- [ ] Evaluation and learning cadence defined.
- [ ] Stop, pivot, and scale criteria documented.

## Scale readiness

A design is ready to scale when the institution can deliver it reliably, govern it, monitor it, fund it, repair it, and learn from it.
