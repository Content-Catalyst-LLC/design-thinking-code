# Validation Protocol

## Data validation

- [ ] Institutional design options are defined.
- [ ] Authority is assessed by decision-rights owners.
- [ ] Capability is assessed by implementation teams.
- [ ] Funding is assessed against actual budget pathways.
- [ ] Policy fit is reviewed by policy/legal experts.
- [ ] Data readiness is reviewed by data owners.
- [ ] Frontline fit is tested with frontline workers.
- [ ] Public value and equity priorities are reviewed with affected groups.
- [ ] Burden is disaggregated by stakeholder group.
- [ ] Risks have named mitigation owners.

## Institutional validation

- [ ] The design has a governance pathway.
- [ ] The design has a maintenance owner.
- [ ] The design has evaluation and learning criteria.
- [ ] The design has stop, pivot, and scale thresholds.
- [ ] The design has community accountability where public value is at stake.
