# Model Card: Institutional Design Readiness Model

## Model name

Institutional Design Readiness and Absorption Model

## Intended use

The model supports structured review of institutional design options before piloting, scaling, or sequencing. It evaluates change readiness, absorption capacity, public value, sequencing need, governance gaps, stakeholder burden, and implementation risk.

## Not intended for

- Automatically choosing institutional strategy.
- Replacing public accountability.
- Replacing legal, compliance, privacy, accessibility, or labor review.
- Certifying a design as ethical or equitable.
- Ignoring community, frontline, or stakeholder knowledge.
- Treating numeric scores as final truth.

## Responsible use

Use the model to identify where governance, capacity, policy, data systems, burden reduction, or implementation planning must be strengthened before a design option moves forward.
