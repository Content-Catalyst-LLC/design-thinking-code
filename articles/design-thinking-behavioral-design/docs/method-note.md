# Method Note: Design Thinking and Behavioral Design

This folder provides a transparent decision-support framework for diagnosing behavioral barriers and prioritizing behavioral design interventions.

The action model is:

\[
P(A) = \sigma(\alpha M + \beta C + \gamma O + \delta T - \lambda F)
\]

The intervention model evaluates expected behavior gain, importance, equity reach, transparency, autonomy preservation, trust effect, accessibility effect, durability, ethical risk, and implementation effort.

A high-priority intervention is not automatically appropriate. It should still be reviewed for transparency, autonomy, fairness, accessibility, privacy, dignity, and unintended consequences.
