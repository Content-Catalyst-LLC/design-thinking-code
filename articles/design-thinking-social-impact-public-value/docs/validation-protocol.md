# Validation Protocol

## Data validation

- [ ] Intervention definitions are clear.
- [ ] Public-value criteria are documented.
- [ ] Community-defined value is included.
- [ ] Burden measures include baseline and post-intervention estimates.
- [ ] Participation records document influence and power sharing.
- [ ] Governance owner is identified.
- [ ] Repair pathway is identified.
- [ ] Implementation risk has a named mitigation owner.
- [ ] Equity outcomes are disaggregated.
- [ ] Stop, pivot, and scale criteria are documented.

## Public-value validation

- [ ] Affected people can review interpretation.
- [ ] Average outcomes do not hide group-level harm.
- [ ] Burden reduction is measured from the stakeholder perspective.
- [ ] Evaluation evidence can change decisions.
- [ ] Stewardship capacity exists after launch.
