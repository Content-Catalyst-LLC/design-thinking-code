# Method Note: Social Impact and Public Value Analysis

This folder provides a transparent decision-support framework for evaluating social impact interventions. It treats public value as a relationship among access, equity, dignity, legitimacy, accountability, outcomes, sustainability, learning, community-defined value, repair capacity, participation quality, governance strength, and stewardship.

## Core models

Public value:

\[
PV_i = w_aA_i + w_eE_i + w_dD_i + w_lL_i + w_cC_i + w_oO_i + w_sS_i + w_rR_i
\]

Impact readiness:

\[
IR_i = \alpha PV_i + \beta F_i + \gamma G_i + \delta T_i - \lambda R_i - \mu B_i
\]

Burden reduction:

\[
BR_g = B_{g,0} - B_{g,1}
\]

## Recommended use

Use this model to support:

- social impact portfolio review;
- public-value prioritization;
- participatory design governance;
- burden audits;
- evaluation planning;
- implementation sequencing;
- stewardship review;
- public-sector and nonprofit design decisions.

## Interpretation

Scores support deliberation. They do not replace community leadership, ethics review, legal review, public accountability, democratic decision-making, or professional judgment.
