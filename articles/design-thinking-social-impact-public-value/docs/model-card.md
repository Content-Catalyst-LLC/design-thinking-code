# Model Card: Public Value and Social Impact Model

## Model name

Public Value and Social Impact Portfolio Model

## Intended use

The model supports structured review of social impact interventions before piloting, implementation, scaling, or stewardship decisions. It evaluates public value, impact readiness, stewardship need, burden risk, governance strength, participation quality, repair capacity, and implementation risk.

## Not intended for

- Automatically deciding funding allocation.
- Replacing community governance.
- Replacing legal, ethical, accessibility, or public accountability review.
- Certifying that an intervention is equitable.
- Treating numeric scores as final truth.
- Ignoring historical injustice, local context, or community-defined value.

## Responsible use

Use the model to identify where participation, governance, burden reduction, evidence, repair pathways, and stewardship must be strengthened before an intervention moves forward.
