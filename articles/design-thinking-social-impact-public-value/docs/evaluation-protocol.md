# Evaluation Protocol

## Purpose

Public-value evaluation should assess outcomes, access, equity, legitimacy, burden, accountability, implementation, and learning.

## Evaluation domains

- Reach.
- Access.
- Outcome.
- Burden.
- Equity.
- Trust and legitimacy.
- Implementation.
- Learning.
- Repair.

## Stop, pivot, and scale criteria

Before implementation, define:

- What evidence justifies scaling.
- What evidence requires redesign.
- What evidence requires stopping.
- What harm triggers escalation.
- Who has authority to pause the intervention.
