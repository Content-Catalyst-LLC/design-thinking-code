# Model Card: Design Evaluation and Learning Evidence Model

## Model name

Design Evaluation, Learning, and Outcome Measurement Model

## Intended use

The model supports transparent comparison of design interventions during evaluation, post-launch learning, service design review, public-sector innovation, organizational learning, implementation science, and applied design research.

## Not intended for

- Automated outcome claims.
- Replacement of evaluation expertise.
- Replacement of stakeholder judgment.
- Replacement of ethical, accessibility, privacy, or equity review.
- Treating before-and-after improvement as causal proof without further analysis.
- Ignoring qualitative evidence, community critique, or subgroup differences.

## Inputs

- Intervention name.
- Intervention type.
- Evaluation stage.
- Outcome improvement.
- Burden reduction.
- Equity performance.
- Trust improvement.
- Durability.
- Operational cost.
- Residual risk.
- Evidence quality.
- Stakeholder coverage.
- Method triangulation.
- Uncertainty.
- Baseline and current quality.
- Optional outcome time series.
- Optional learning agenda.
- Optional evaluation risk register.

## Outputs

- Evaluation value.
- Evidence-adjusted value.
- Evidence strength.
- Learning priority.
- Accountability index.
- Learning value.
- Scenario rankings.
- Monte Carlo rank stability.
- Bootstrap stability.
- Random-weight sensitivity.
- Outcome learning summary.
- Learning agenda review.
- Risk-register priority.

## Limitations

The model cannot determine whether a design intervention caused observed outcomes. Causal claims require stronger evaluation designs, comparison groups, time-series reasoning, mixed-method interpretation, and attention to confounding.

## Responsible use

Use the model as a deliberation and documentation tool. Treat uncertainty, weak coverage, equity gaps, high residual risk, and unstable rankings as reasons for further inquiry.
