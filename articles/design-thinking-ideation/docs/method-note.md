# Method Note: Professional Ideation Portfolio Scoring

This folder provides a transparent decision-support framework for ideation in design thinking.

The model compares candidate ideas across six criteria:

\[
V_i = w_d D_i + w_f F_i + w_n N_i + w_e E_i + w_l L_i - w_r R_i
\]

Where:

- **Desirability** captures whether the idea addresses a real stakeholder need or tension.
- **Feasibility** captures whether the idea can be built, tested, operated, or supported with available capability.
- **Novelty** captures exploratory value and the ability to challenge default assumptions.
- **Equity value** captures whether the idea reduces burden, improves access, and supports less visible or more affected stakeholders.
- **Learning value** captures whether prototyping the idea would teach the team something important.
- **Composite risk** captures unresolved ethical, operational, technical, scaling, and implementation risk.

A more granular risk index may be represented as:

\[
R_i = \lambda_H H_i + \lambda_O O_i + \lambda_T T_i + \lambda_S S_i
\]

Where:

- \(H_i\) = ethical risk;
- \(O_i\) = operational risk;
- \(T_i\) = technical risk;
- \(S_i\) = scaling risk.

## Professional interpretation

The score is not a final answer. It is a structured prompt for design judgment.

A strong ideation process should ask:

- What insight produced this idea?
- Which stakeholder need or tension does it address?
- What kind of prototype could test it?
- What burden might it shift?
- Which stakeholders benefit most?
- Which stakeholders could be harmed or excluded?
- What evidence supports the idea?
- What would make the idea fail?
- What would the team learn by testing it?

## Recommended use

Use this model to support:

- idea portfolio review;
- concept selection;
- prototype prioritization;
- convergence workshops;
- risk review;
- equity review;
- learning-oriented experimentation planning;
- decision documentation.
