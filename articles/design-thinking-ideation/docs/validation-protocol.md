# Validation Protocol

Use this checklist before interpreting model outputs.

## Data validation

- [ ] Every candidate idea has a clear name.
- [ ] No duplicate candidate ideas exist.
- [ ] Every idea has a cluster.
- [ ] All required criteria are present.
- [ ] All required scores are numeric.
- [ ] Scores are in the expected range.
- [ ] Scenario weights sum to 1.0.
- [ ] Risk components are documented.
- [ ] Evidence quality is documented.
- [ ] Prototype testability is documented.
- [ ] Cluster diagnostics are documented.

## Design validation

- [ ] Each idea is traceable to stakeholder research or insight.
- [ ] Each idea has a testable prototype pathway.
- [ ] Equity implications are reviewed.
- [ ] Ethical risks are reviewed.
- [ ] Operational risks are reviewed.
- [ ] Technical risks are reviewed.
- [ ] Scaling risks are reviewed.
- [ ] Potential burden shifting is reviewed.
- [ ] Alternative ideas in the same cluster are documented.
- [ ] Selection criteria are explicit.

## Interpretation validation

- [ ] Rankings are compared across scenarios.
- [ ] Monte Carlo stability is reviewed.
- [ ] Weight sensitivity is reviewed.
- [ ] High-risk ideas are not moved directly into implementation.
- [ ] High-learning ideas are considered for prototype testing.
- [ ] Cluster breadth is reviewed to avoid false divergence.
- [ ] The next prototype, research, or refinement step is clearly defined.
