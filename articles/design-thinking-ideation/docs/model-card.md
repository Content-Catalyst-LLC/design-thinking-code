# Model Card: Ideation Portfolio Decision-Support Model

## Model name

Candidate Idea Portfolio Value Model

## Intended use

The model supports transparent comparison of candidate ideas during ideation review, convergence, prototype planning, design research synthesis, and responsible innovation decision-making.

## Not intended for

- Automated idea selection.
- Replacement of stakeholder judgment.
- Replacement of ethical review.
- Declaring an idea ready for implementation without prototyping.
- Ranking people, communities, or stakeholders.
- Justifying a favored idea without evidence.
- Treating desirability, feasibility, novelty, equity, or learning value as objective facts.

## Inputs

- Candidate idea.
- Idea cluster.
- Desirability score.
- Feasibility score.
- Novelty score.
- Equity value score.
- Learning value score.
- Residual, ethical, operational, technical, and scaling-risk scores.
- Optional evidence quality.
- Optional prototype testability.
- Optional implementation relevance.
- Optional cluster diagnostics.

## Outputs

- Weighted idea value.
- Composite risk index.
- Prototype priority.
- Confidence-adjusted value.
- Review priority.
- Rank within scenario.
- Monte Carlo rank stability.
- Bootstrap stability.
- Weight sensitivity summary.
- Cluster breadth diagnostics.

## Assumptions

The model assumes that idea scores are provisional and that weights represent explicit strategic or research priorities. It also assumes that uncertainty, ethical risk, operational risk, stakeholder burden, and evidence limitations should be documented rather than hidden.

## Limitations

The model cannot determine whether an idea is correct, ethical, feasible, scalable, or contextually appropriate by itself. Those judgments require stakeholder engagement, domain expertise, qualitative interpretation, prototyping, testing, and governance.

## Responsible use

Use this model as a documentation and deliberation tool. Treat disagreement about scores, weights, risks, or priorities as useful evidence that the design team needs further inquiry.
