# Method Note: Design Thinking and Strategy

This folder provides a transparent decision-support framework for evaluating strategic options through design-thinking criteria: human desirability, feasibility, viability, strategic alignment, ethical quality, learning value, evidence strength, implementation effort, strategic risk, capability gaps, public value, and time-to-learn.

The model is:

\[
S_i = w_dD_i + w_fF_i + w_vV_i + w_aA_i + w_eE_i + w_lL_i + w_pP_i + w_qQ_i - w_rR_i - w_cC_i - w_gG_i - w_tT_i
\]

## Recommended use

Use this model to support:

- strategic option review;
- design strategy portfolio planning;
- public value strategy review;
- strategic assumption testing;
- service and implementation strategy;
- innovation portfolio governance;
- AI/data strategy evaluation;
- organizational change strategy;
- ethics and power review;
- strategic learning governance.

## Interpretation

A high strategic score is not a final decision. It is a structured prompt for deeper review, prototype evidence, stakeholder participation, implementation readiness, public value analysis, and governance.
