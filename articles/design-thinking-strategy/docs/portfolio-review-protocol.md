# Portfolio Review Protocol

## Purpose

A strategic portfolio should balance improvement, learning, capability building, equity, public value, implementation readiness, and risk.

## Portfolio roles

- `scale_or_commit`: strong score, acceptable risk, and implementation readiness.
- `prototype_and_learn`: high learning value but meaningful uncertainty.
- `public_value_or_legitimacy_bet`: strong ethical/public value contribution.
- `capability_required`: promising option that requires capability building first.
- `sequence_after_learning`: option should follow additional evidence or sequencing.

## Review questions

- Which options are ready to commit?
- Which options should be prototyped?
- Which options require capabilities first?
- Which options create public value or legitimacy?
- Which options have high uncertainty and high ethical sensitivity?
- Which options should be stopped, delayed, or reframed?
