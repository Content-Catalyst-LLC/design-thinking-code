# Validation Protocol

## Data validation

- [ ] Every strategic option has a unique name.
- [ ] Every score uses a documented scale.
- [ ] Evidence strength is in [0, 1].
- [ ] Scenario weights sum to 1.0.
- [ ] Assumptions have importance, confidence, and test plans.
- [ ] Risk-register entries have owners and mitigation status.

## Strategy validation

- [ ] Human desirability is based on evidence, not assumption.
- [ ] Feasibility includes technical and operational constraints.
- [ ] Viability includes resource and institutional constraints.
- [ ] Ethical quality includes burden, dignity, power, and exclusion.
- [ ] Public value is considered where relevant.
- [ ] Implementation readiness is reviewed.
- [ ] Learning thresholds are defined.
- [ ] Stop, pivot, and scale rules are explicit.

## Outcome claim validation

- [ ] Strategic success is not inferred from activity alone.
- [ ] Prototype evidence is distinguished from scale evidence.
- [ ] Average outcomes are checked against equity and burden.
- [ ] Governance responsibility is documented.
