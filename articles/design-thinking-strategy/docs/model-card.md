# Model Card: Design-Thinking Strategy Option Model

## Model name

Design-Thinking Strategy Option Scoring and Portfolio Model

## Intended use

The model supports transparent review of strategic options across desirability, feasibility, viability, strategic alignment, ethical quality, public value, learning value, evidence strength, implementation effort, strategic risk, capability gap, and time-to-learn.

## Not intended for

- Automated investment or executive decision-making.
- Replacing stakeholder deliberation.
- Replacing financial, operational, legal, technical, or governance review.
- Ranking public priorities without democratic or institutional accountability.
- Treating strategy as a numerical optimization problem.

## Outputs

- Strategic score.
- Portfolio value.
- Uncertainty priority.
- Implementation readiness.
- Ethical public value index.
- Portfolio role.
- Scenario rankings.
- Monte Carlo rank stability.
- Bootstrap stability.
- Random-weight sensitivity.
- Assumption test priorities.
- Risk-register priority.

## Responsible use

Use this model to make assumptions and trade-offs visible. A strategy remains a matter of judgment, responsibility, governance, power, and learning.
