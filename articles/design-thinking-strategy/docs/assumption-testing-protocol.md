# Assumption Testing Protocol

## Purpose

Strategic assumptions should be made explicit before scaling. Design thinking strengthens strategy by turning assumptions into testable hypotheses.

## Required fields

- Strategic option.
- Assumption.
- Assumption type.
- Importance.
- Current confidence.
- Evidence source.
- Test method.
- Test cost.
- Time to test.
- Ethical sensitivity.
- Decision threshold.
- Stop, pivot, or scale rule.

## Common assumption types

- User behavior.
- Stakeholder trust.
- Service delivery.
- Technical feasibility.
- Operational capacity.
- Financial viability.
- Governance readiness.
- Data quality.
- Partnership commitment.
- Adoption behavior.
- Public value or legitimacy.

## Scale rule

Do not scale a strategic option when a high-importance, high-ethical-sensitivity assumption remains low-confidence and untested.
