# Validation Protocol

## Data validation

- [ ] Stakeholder groups are defined.
- [ ] Affectedness is documented.
- [ ] Inclusion and burden scores use a documented scale.
- [ ] Design decisions have harm, exposure, detectability, accountability, and repairability estimates.
- [ ] Participation power is separated from mere presence.
- [ ] Governance risks have owners.
- [ ] Repair pathways are documented.

## Ethical validation

- [ ] Affected groups can challenge interpretation.
- [ ] High-burden groups are not excluded from research.
- [ ] Accessibility review is complete.
- [ ] Participation is not mislabeled as co-design.
- [ ] Privacy, autonomy, and manipulation risk are reviewed.
- [ ] Post-launch harm monitoring is defined.
- [ ] Stop or pause thresholds are explicit.
