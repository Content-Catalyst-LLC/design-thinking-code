# Rollout Governance Protocol

## Purpose

This protocol helps teams move from prototype validation to responsible implementation and scale.

## Governance roles

- **Implementation owner:** accountable for rollout decisions and ongoing operation.
- **Service owner:** accountable for the lived service experience and support pathways.
- **Technical owner:** accountable for reliability, monitoring, data flows, and security.
- **Equity owner:** accountable for differential access, burden, and outcomes.
- **Evaluation owner:** accountable for evidence quality and post-deployment learning.
- **Frontline liaison:** accountable for surfacing staff burden, workarounds, and issue patterns.

## Review cadence

- Pre-launch readiness review.
- Stage-gate review after internal simulation.
- Stage-gate review after controlled pilot.
- Multi-site adaptation review.
- Phased rollout review.
- Post-launch learning review.
- Retirement or redesign review.

## Decision options

- Continue as planned.
- Continue with safeguards.
- Narrow scope.
- Add support capacity.
- Revise the intervention.
- Run additional testing.
- Pause rollout.
- Retire the intervention.
