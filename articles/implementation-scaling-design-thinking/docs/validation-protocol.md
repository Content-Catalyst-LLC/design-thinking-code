# Validation Protocol

## Data validation

- [ ] Every intervention has a unique name.
- [ ] Intervention type and implementation stage are documented.
- [ ] Adoption, operations, durability, governance, equity, and financial scores are documented.
- [ ] Risk components are documented.
- [ ] Evidence quality is documented.
- [ ] Stakeholder coverage is documented.
- [ ] Context complexity and scale sensitivity are documented.
- [ ] Scenario weights sum to 1.0.
- [ ] Rollout-stage metrics are traceable.
- [ ] Risk-register entries have owners and mitigation status.

## Implementation validation

- [ ] Core mechanisms and adaptable components are documented.
- [ ] Governance ownership is assigned.
- [ ] Escalation and exception pathways are clear.
- [ ] Staff training and support are tested.
- [ ] Technical monitoring and recovery plans exist.
- [ ] Equity monitoring is defined.
- [ ] Post-deployment learning cadence is assigned.
- [ ] Rollback or pause criteria are documented.

## Scale validation

- [ ] Context variation has been assessed.
- [ ] Scale sensitivity has been modeled.
- [ ] Multi-site or staged rollout evidence has been reviewed.
- [ ] Local adaptation rules are documented.
- [ ] Drift detection is planned.
- [ ] Scaling does not amplify unresolved risks.
