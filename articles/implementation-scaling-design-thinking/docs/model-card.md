# Model Card: Implementation and Scaling Evidence Model

## Model name

Implementation and Scaling Readiness Model

## Intended use

The model supports transparent comparison of implementation candidates during design thinking, service design, civic design, implementation science, public-sector innovation, organizational learning, and applied research workflows.

## Not intended for

- Automated scale decisions.
- Replacement of stakeholder judgment.
- Replacement of governance review.
- Replacement of ethical, accessibility, or equity review.
- Treating pilot success as proof of broad scalability.
- Ignoring local context, power, burden, or institutional constraints.

## Inputs

- Intervention name.
- Intervention type.
- Implementation stage.
- Adoption readiness.
- Operational fit.
- Durability.
- Governance readiness.
- Equity readiness.
- Financial sustainability.
- Operational, governance, technical, equity, and financial risk.
- Evidence quality.
- Stakeholder coverage.
- Context complexity.
- Scale sensitivity.
- Optional rollout-stage metrics.
- Optional risk register.

## Outputs

- Implementation value.
- Evidence-adjusted value.
- Scaled quality estimate.
- Composite risk.
- Implementation review priority.
- Scale readiness.
- Governed durability index.
- Scenario rankings.
- Monte Carlo rank stability.
- Bootstrap stability.
- Random-weight sensitivity.
- Rollout learning summary.
- Risk-register priority.

## Limitations

The model cannot determine whether an intervention is ready to scale by itself. Scaling requires institutional judgment, governance, local knowledge, equity monitoring, public accountability, and post-deployment learning.

## Responsible use

Use the model as a deliberation and documentation tool. Treat uncertainty, unstable rankings, governance weakness, equity risk, and scale degradation as reasons for further inquiry.
