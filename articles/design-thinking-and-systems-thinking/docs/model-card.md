# Model Card: Design-System Intervention Model

## Model name

Design Thinking and Systems Thinking Intervention Model

## Intended use

The model supports transparent comparison of design-system interventions that must be judged across lived experience and system structure.

## Not intended for

- Automated policy or system-redesign decisions.
- Replacement of stakeholder research.
- Replacement of governance review.
- Replacement of ethical, accessibility, privacy, or equity review.
- Treating model outputs as causal proof.
- Ignoring qualitative evidence, local knowledge, or power analysis.

## Inputs

- Intervention name.
- Intervention type.
- Leverage level.
- Human-centered value.
- Systemic leverage.
- Feasibility.
- Equity sensitivity.
- Durability.
- Risk.
- Evidence quality.
- Stakeholder coverage.
- Context complexity.
- Delay sensitivity.
- Burden-shift risk.
- Optional feedback dynamics.
- Optional risk register.

## Outputs

- System design value.
- Evidence-adjusted value.
- Context-adjusted value.
- Evidence strength.
- Learning priority.
- Deep leverage index.
- Burden-shift index.
- Scenario rankings.
- Monte Carlo rank stability.
- Bootstrap stability.
- Random-weight sensitivity.
- Feedback dynamics summary.
- Risk-register priority.

## Limitations

The model cannot represent full system complexity. It is a structured decision-support tool that helps teams make assumptions visible. It should be used alongside system maps, service evidence, stakeholder research, institutional analysis, and longitudinal evaluation.

## Responsible use

Use the model to support deliberation, not to replace it. Treat uncertainty, weak coverage, high burden-shift risk, high delay sensitivity, and unstable rankings as reasons for further inquiry.
