# System Mapping Template

## Purpose

Use this template to connect human-centered evidence with system structure.

## Core mapping questions

1. What lived experience triggered the inquiry?
2. What recurring pattern does the experience reveal?
3. Which actors, institutions, technologies, rules, and resources shape the pattern?
4. What feedback loops reinforce or balance the pattern?
5. What delays make consequences difficult to see?
6. Where does burden accumulate or shift?
7. Who has authority to change the system?
8. What leverage levels are available?
9. What risks or unintended consequences should be monitored?
10. What evidence would show that system behavior changed?

## Suggested map layers

| Layer | Evidence | Artifact |
|---|---|---|
| Lived experience | Interviews, observations, complaints, service journeys | Journey map |
| Service structure | Roles, handoffs, touchpoints, backstage work | Service blueprint |
| Institutional structure | Rules, incentives, decision rights, resources | Governance map |
| System dynamics | Feedback loops, delays, accumulations, adaptation | Causal loop diagram |
| Evaluation | Outcomes, burden, equity, trust, drift, risk | Learning agenda |
