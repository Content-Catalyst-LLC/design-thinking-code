# Metadata Governance Protocol

## Purpose

Metadata allows research evidence to be reused responsibly.

## Required metadata

- Evidence ID.
- Evidence type.
- Source owner.
- Collection date.
- Method.
- Participant group or data population.
- Consent status.
- Reuse limits.
- AI-use status.
- Reviewer.
- Limitations.
- Decision link.
- Retention rule.
- Access classification.

## Reuse guidance

Do not reuse research evidence when consent status, limitations, participant group, or retention rules are missing.
