# AI Use Protocol for Design Research

## Purpose

AI-assisted research should support retrieval, transcription, coding, clustering, summarization, and synthesis without replacing human interpretation or participant knowledge.

## Required documentation

- Research task.
- AI tool class.
- Model/version if available.
- Input source type.
- Sensitive data status.
- Prompt or instruction record.
- Output file or artifact ID.
- Human reviewer.
- Source-grounding status.
- Hallucination review.
- Minority signal review.
- Consent and reuse status.

## Red flags

- AI-generated insight without source links.
- AI summary accepted without human review.
- Personas generated without participant evidence.
- Edge cases collapsed into majority themes.
- Sensitive transcripts processed without review.
- Synthetic users replacing real participant research.
