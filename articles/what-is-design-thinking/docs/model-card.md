# Model Card: Design Strategy Decision-Support Model

## Model name

Design Pathway Value Model

## Intended use

The model supports transparent comparison of design thinking pathways during research synthesis, strategy review, prototyping decisions, and early implementation planning.

## Not intended for

- Automated decision-making.
- Replacement of stakeholder research.
- Replacement of domain expertise.
- Final approval of public policy, clinical, educational, financial, or safety-critical interventions.
- Ranking people or communities.

## Inputs

- Pathway name.
- Human-centered relevance score.
- Feasibility score.
- Learning value score.
- Residual risk score.
- Optional stakeholder confidence.
- Optional evidence quality.
- Optional implementation complexity.

## Outputs

- Weighted design value.
- Rank within scenario.
- Monte Carlo rank stability.
- Bootstrap stability.
- Weight sensitivity summary.

## Assumptions

The model assumes that pathway scores are provisional and that weights represent explicit institutional priorities. It also assumes that uncertainty should be modeled rather than hidden.

## Limitations

The model cannot determine whether a design pathway is morally legitimate, politically acceptable, historically informed, equitable, or contextually appropriate. Those judgments require human deliberation, stakeholder participation, domain expertise, and ethical review.

## Responsible use

Use this model as a documentation and deliberation tool. Treat disagreement about scores or weights as useful evidence that the design team needs further inquiry.
