# Model Card: Problem-Framing Decision-Support Model

## Model name

Problem Frame Value Model

## Intended use

The model supports transparent comparison of candidate problem frames during research synthesis, strategy review, stakeholder deliberation, and prototype prioritization.

## Not intended for

- Automated problem definition.
- Replacement of stakeholder research.
- Replacement of domain expertise.
- Final approval of public policy, clinical, educational, financial, or safety-critical interventions.
- Declaring a frame “correct” without evidence.
- Silencing disagreement among stakeholders.

## Inputs

- Candidate problem frame.
- Explanatory adequacy score.
- Stakeholder/system coverage score.
- Opportunity value score.
- Framing risk score.
- Optional risk components.
- Optional evidence quality.
- Optional frame confidence.
- Optional implementation scope.
- Optional counterframes.

## Outputs

- Weighted frame value.
- Framing-risk index.
- Confidence-adjusted value.
- Rank within scenario.
- Monte Carlo rank stability.
- Bootstrap stability.
- Weight sensitivity summary.
- Counterframe test priority.

## Assumptions

The model assumes that frames are provisional and that weights represent explicit institutional priorities. It also assumes that uncertainty, power, and counterframes should be documented rather than hidden.

## Limitations

The model cannot determine whether a frame is morally legitimate, politically acceptable, historically informed, equitable, or contextually appropriate. Those judgments require human deliberation, stakeholder participation, fieldwork, systems analysis, and ethical review.

## Responsible use

Use this model as a documentation and deliberation tool. Treat disagreement about scores, weights, and counterframes as useful evidence that the design team needs further inquiry.
