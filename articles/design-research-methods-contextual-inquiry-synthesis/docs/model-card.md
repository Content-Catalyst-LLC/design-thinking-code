# Model Card: Contextual Inquiry Synthesis Model

## Model name

Contextual Inquiry Theme Confidence Model

## Intended use

The model supports transparent documentation of qualitative design research synthesis. It helps teams summarize themes, identify evidence gaps, review stakeholder coverage, compare methods, and prioritize validation.

## Not intended for

- Automated qualitative interpretation.
- Replacing researcher judgment.
- Replacing stakeholder validation.
- Declaring a theme universally true.
- Statistical population inference without appropriate sampling.
- Ranking participants or communities.
- Ignoring sensitive context or contradictory evidence.

## Inputs

- Evidence unit identifiers.
- Participant groups.
- Research methods.
- Primary and secondary themes.
- Evidence strength.
- Interpretive risk.
- Environmental constraint.
- Artifact dependency.
- Workflow stage.
- Privacy sensitivity.
- Power asymmetry.

## Outputs

- Theme synthesis confidence.
- Validation priority.
- Contextual depth index.
- Ethics review priority.
- Theme network centrality.
- Stakeholder sampling diagnostics.
- Saturation curve.
- Coder agreement summary.
- Monte Carlo rank stability.
- Bootstrap stability.

## Limitations

The model cannot determine the meaning of a theme by itself. It can only help document and structure evidence. Researchers must read the underlying material, review context, engage affected stakeholders, preserve uncertainty, and avoid overclaiming.

## Responsible use

Use the model as a research documentation and deliberation tool. Treat disagreement, instability, and missing evidence as signals for further inquiry.
