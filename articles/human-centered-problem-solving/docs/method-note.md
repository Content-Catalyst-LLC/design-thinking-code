# Method Note: Professional Human-Centered Option Scoring

This folder provides a transparent decision-support framework for human-centered problem solving.

The model compares possible design options across four criteria:

\[
V_i = w_b B_i + w_u U_i + w_s S_i - w_c C_i
\]

Where:

- **Human benefit** captures the degree to which an option improves lived experience, dignity, usefulness, access, safety, trust, or practical outcome.
- **Usability** captures intelligibility, ease of use, cognitive clarity, accessibility, and fit with human attention and mental models.
- **Stakeholder fit** captures how well the option serves multiple affected groups, especially those who may be less visible to the institution.
- **Burden** captures user cost, including time, confusion, documentation work, emotional strain, access barriers, stigma, and uncertainty.

A more granular burden index may be represented as:

\[
C_i = \lambda_L L_i + \lambda_K K_i + \lambda_P P_i + \lambda_A A_i
\]

Where:

- \(L_i\) = learning cost;
- \(K_i\) = compliance cost;
- \(P_i\) = psychological cost;
- \(A_i\) = access cost.

## Professional interpretation

The score is not a final answer. It is a structured prompt for judgment.

A strong professional design process should ask:

- Who assigned the scores?
- What evidence supports each score?
- Which stakeholders were included?
- Which stakeholders were missing?
- What assumptions are embedded in the weights?
- What forms of burden are easiest for the institution to overlook?
- What evidence would change the ranking?
- Which option should be prototyped before implementation?
- Which risk is unacceptable even if the option scores well?

## Recommended use

Use this model to support:

- early-stage human-centered strategy;
- public-sector service redesign;
- healthcare pathway improvement;
- administrative-burden reduction;
- user-research synthesis;
- civic technology evaluation;
- design option prioritization;
- prototype portfolio selection;
- research documentation.
