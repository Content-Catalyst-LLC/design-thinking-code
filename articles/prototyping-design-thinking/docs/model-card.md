# Model Card: Prototype Portfolio Decision-Support Model

## Model name

Prototype Learning and Readiness Model

## Intended use

The model supports transparent comparison of candidate prototypes during design thinking, service design, UX research, civic design, public-sector innovation, organizational learning, and applied design research.

## Not intended for

- Automated prototype selection.
- Replacement of stakeholder judgment.
- Replacement of ethical review.
- Treating prototype results as implementation proof.
- Ignoring accessibility, privacy, power, or equity concerns.
- Launch decisions without additional evidence.

## Inputs

- Prototype name.
- Prototype type.
- Fidelity level.
- Learning gain.
- Feasibility signal.
- User response.
- Equity value.
- Implementation relevance.
- Ethical, operational, technical, and scaling-risk scores.
- Evidence quality.
- Prototype testability.
- Stakeholder coverage.
- Optional iteration rounds.
- Optional risk register.

## Outputs

- Prototype value.
- Composite risk.
- Confidence-adjusted value.
- Review priority.
- Advance readiness.
- Scenario ranking.
- Monte Carlo rank stability.
- Bootstrap stability.
- Weight sensitivity.
- Iteration improvement.
- Risk-register priority.

## Limitations

The model cannot determine whether a prototype is correct, ethical, usable, or ready for implementation. Those judgments require user research, stakeholder validation, domain expertise, accessibility review, security review, governance, and operational testing.

## Responsible use

Use the model as a deliberation and documentation tool. Treat uncertainty, disagreement, and unstable rankings as reasons for further inquiry rather than as defects in the process.
