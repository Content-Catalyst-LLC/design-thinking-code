# Validation Protocol

## Data validation

- [ ] Every prototype has a unique name.
- [ ] Prototype type and fidelity level are documented.
- [ ] Learning, feasibility, response, equity, and implementation scores are documented.
- [ ] Risk components are documented.
- [ ] Evidence quality is documented.
- [ ] Stakeholder coverage is documented.
- [ ] Scenario weights sum to 1.0.
- [ ] Iteration-round data is traceable.
- [ ] Risk-register entries have owners and mitigation status.

## Design validation

- [ ] Each prototype has a learning question.
- [ ] Fidelity matches the learning question.
- [ ] Ethical risks are reviewed.
- [ ] Accessibility and inclusion risks are reviewed.
- [ ] Stakeholder groups include high-burden and edge-case participants.
- [ ] Prototype results are interpreted in context.
- [ ] Limits of test conditions are documented.
- [ ] Next-step decisions are documented.

## Decision validation

- [ ] Rankings are compared across scenarios.
- [ ] Monte Carlo rank stability is reviewed.
- [ ] Weight sensitivity is reviewed.
- [ ] High-risk prototypes receive additional safeguards.
- [ ] High-learning prototypes are not prematurely discarded.
- [ ] Pilot readiness is distinguished from launch readiness.
